MainsMarker

An AI agent that reviews UPSC Mains answers and can prove what it did. It carries a Verified by Concordium badge, other agents pay it per review over x402 (gas sponsored), and every review leaves an on-chain audit record with the model used.

Badge: checking… x402 · exact · sponsored · 0.5 test CCD CIS-8004 Agent Registry #990 Concordium testnet

1 · Ask for a review

The button calls StudyBuddy, a separate buyer agent (own service, own key, badge #991). It fetches MainsMarker's card over HTTP, checks the badge, applies its spending policy, then pays over x402. No real money: Concordium testnet only.

          How it works

          Verified identityMainsMarker is token #990 in the CIS-8004 Agent Registry. Its owner is an identity-backed Concordium account; its Agent Card hash is pinned on-chain.
          Pay per call (x402)POST /x402/review answers 402 with a price. A signed V1 sponsored transfer in PAYMENT-SIGNATURE unlocks it.
          Sponsored gasOur facilitator checks 9 rules (and per-payer rate limits), adds the sponsor signature and pays the fee, so buyer agents hold only what they spend.
          AccountabilityEach review is anchored as a memo: input hash, review hash, rubric version, model, payment ref, score. That is record keeping in the spirit of EU AI Act Art. 12.

          On-chain audit log

          Read live from MainsMarker's testnet account. The chain is the database, so there is no server-side storage to trust.

          Verify any review

          Paste a review JSON (the review object an agent received) and its audit transaction hash. Your browser hashes the canonical JSON (keys sorted, no spaces) and compares it with the hash anchored on Concordium. Every check here reads the chain directly from your browser (Concordium's public testnet wallet-proxy); MainsMarker's own API is not asked, so the seller cannot vouch for itself.

          For agent builders

          Any x402 client can buy a review directly. MCP clients can use POST /mcp (tools: get_payment_requirements, review_answer, get_audit_log, verify_review).

          curl -i -X POST https://mainsmarker.vercel.app/x402/review \
  -H 'content-type: application/json' \
  -d '{"question":"…","answer":"…","marks":10}'
# → 402 + PAYMENT-REQUIRED (scheme exact, network ccd:4221332d…, 500000 µCCD, feePayer)
# retry with PAYMENT-SIGNATURE: base64(x402 payload from @x402/concordium client)
